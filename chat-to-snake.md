## 结论：不是「不打」，是**要挑着打**——而且得先把 `google` 这个前缀剥掉

我上一轮的建议本来就是从长尾切。所以这个问题真正值得回答的是：**长尾里哪些能打**。刚查完，两个候选一开一锁：

| 长尾词                | 月搜索量 | 哥飞版难度    | 盘面                                           |
| --------------------- | -------: | ------------- | ---------------------------------------------- |
| **google snake mods** |   49,500 | **40.1 中等** | **开着**——有个 DR 0 的 10 个月新站排在首页第 8 |
| snake game unblocked  |   22,200 | **70.2 困难** | **锁死**——8 席被 DR 57~100 的大站占满，无弱位  |

---

### 一、带品牌前缀的长尾，前十大半是品牌方自己的地盘

哥飞在 2025-07-17 的小课堂里，拿 elevenlabs 讲过这件事（[原文](https://new.web.cafe/tutorial/detail/yv34j983sr)，作者哥飞，2025-10-10 发布）：

> 「这里的大需求，既可以是需求关键词，也可以品牌词。」
> 「注意，如果你直接拿 elevenlabs voice isolator 去谷歌搜索，那么得到的搜索结果，肯定大部分都是 elevenlabs 的内页。**因为用户会把品牌词放到前面，本来想要找的就是这个网站下的某个功能。所以我们去看关键词时，就要把 elevenlabs 去掉，只看 voice isolator。**」

对应到 snake 就一目了然：`google snake game` 前十有 **4 席是谷歌自家的域**（google.com、sites.google.com、play.google.com、chromewebstore.google.com），`snake game unblocked` 里 `sites.google.com` 还占两席。**这些词的「长尾」如果连品牌一起打，你打的是谷歌的家门。**

所以正确动作是**把品牌词剥掉看剩下的需求词**——`snake mods`、`snake game unblocked`。剥掉之后才有独立站的空间：elevenlabs 那个案例里，`voiceisolator.io` 就是拿关键词注册域名、**外链域名才 30 个**就拿到排名（哥飞原话：「我们群里的朋友，应该都能够轻松给自己网站搞到 30 个外链吧」）。

### 二、`google snake mods` 这条路是通的，有活证据

- 第 1 位 **googlesnakemods.com**——域名直拼关键词，DR 36、只 2.8 年，月访问 **12.9 万**；
- 第 8 位 **googlesnakemods.org**——**DR 0、注册 10 个月**，月访问 6,445，照样进了第一页。

这就是「**年轻域名低 DR 却排上高位 = 赛道对新站友好**」的活证据。工具的原话是：这个词「对认真做页面的后来者是开放的」。真正可争的席位是 **2 个 EMD + fandom + scratch 那 4 席**，其余 4 席是 youtube（3 个）和 github 的平台固定位——**抢不到，但可以蹭**（配一条同词视频，有机会在同一页多占一个位置）。

### 三、为什么另外那个「长尾」不能碰

`snake game unblocked` 的 70.2 分不是虚的。前十：mathsisfun（DR 80）、googlesnake.gitlab.io（DR 89）、sites.google.com ×2（DR 100）、play.google.com（DR 100）、snakeio-unblocked.github.io（DR 94）、crazygames（DR 81）、snake.io（DR 57）、chromewebstore（DR 100）、poki（DR 79）。

**注意第 2、5 位那两个看着像小站的名字**——`gitlab.io` / `github.io` 的子域，DR 是从平台继承来的（89 / 94），**不是弱位，是伪装成弱位的大站**。整页没有可超越的占位，新站进去最多陪跑。

### 四、长尾本身的三个硬约束（决定了它只能是「切入口」，不是「终点」）

1. **天花板在主词下面**：最大的长尾 49,500，是主词 368,000 的 **13.4%（约 1/7.4）**；unblocked 只有 6%。而且这批词的趋势全是下滑，-67% 到 -76%。
2. **长尾页一样被平台占位**：mods 的前 8 席里 4 席是 youtube / github / fandom / scratch 这类抢不到的位置。
3. **需求坐过山车**：主词从 60,500 冲到 150 万再回落，长尾跟着同步波动——**排名能做，收入要按波动算**。

另外，社群成员 laiqun🇨🇳 在《GSC 排名·曝光·点击 数据模拟器》里（[帖子](https://new.web.cafe/topic/h8tw10f4i6)，2026-05-27）给的阶段建议正好对上：权重没起来时「**90% 精力做长尾精品页，10% 做品牌词，大词暂时不碰**」。

### 所以路径应该是这样

1. **先做 `google snake mods`**——KD 40.1 中等，有 DR 0 新站进前十的活证据，且第 1 位那个站只靠 30~50 量级的外链就立住了；
2. **别用 google 拼域名**：两个 `googlesnakemods.*` 都已被占且在运营，直接蹭品牌还有商标风险，用非品牌域名做；
3. **抄作业最快**：把 googlesnakemods.com 的外链按发现时间倒序拆一遍，看它起步阶段发在哪——这是哥飞说的「有手就行，甚至不需要思考」。

我可以马上做两件事：**用 Ahrefs 读 googlesnakemods.com 的外链清单和流量曲线**（看它靠几十个什么外链起的、什么时候起的），或者**顺着 mods 再往下摸一层**（nuke、level editor、mod loader 那一串衍生词谁的量够、谁的盘面空）。你说哪个，我就开查。

### 一、两个依赖关系搞反了

**① FAQ 不是首页的前置产物，它是首页的第 6 区块。**

我上一轮给的方案里，FAQ（H2）就排在 How to Play 下面、内链块上面。它和 Title、H1、FAQPage 结构化数据是**同一个交付物**——把文案先拆出去单独交，等于把一页纸剪成两半寄。而且它跟骨架是**双向依赖**：FAQPage 的 schema 要嵌 FAQ 文本，FAQ 文本要嵌进骨架的 DOM 结构。写的时候可以先后，上线时必须同时。

**② 矩阵页的内链锚文本，必须以首页目标词为准。**

这是哥飞讲内链时说得最清楚的一条。他在 1 群说（2025-03-02）：

> 「为了让首页有更高的权重，一般都会在**每一个内页增加到首页的内链**，这样就能够把每一个内页的权重传递到首页。」

方向是**内页 → 首页**。所以首页是整个内链结构的**落点**——矩阵页先上线、首页还没上，那些内链指向的就是一个**不存在的页面（404）**。矩阵页可以**起草**，但锚文本和内链结构必须等首页定稿才能封版。社群成员 Banbri 在 1 群讲过的经验也是这个次序（2023-10-07）：「先做首页，加尽可能多的 h2 跟你想优化的新词相关……**之后加内页**，每天更新一点。」（这是群友的实践，不是哥飞的方法论）

### 二、第三个理由：工作量分布反了

这三样里，**首页骨架是那根最长的杆子**——canvas 游戏逻辑（21×15 网格 + 三档速度 + 双输入通道 + 本地最高分）+ PWA manifest + 两套结构化数据，这是整个项目里最耗工的部分。

**把最长的那根杆子排在最后，等于把整个项目的交付时间拉长。** FAQ 英文成稿和矩阵页文案加起来不到一小时的活，首页骨架是几天的事。按你的顺序，你要先把快的两样做完，然后才开始等最慢的那一步——中间没有任何一步能上线。

      (function () {
        const canvas = document.getElementById("game");
        const ctx = canvas.getContext("2d");
        const COLS = 21,
          ROWS = 15;
        const CELL = canvas.width / COLS;
        const SPEEDS = { 150: "Slug", 100: "Worm", 50: "Python" };

        let stepMs = 100,
          timer = null,
          running = false,
          paused = false;
        let snake, dir, queue, food, score;

        const elScore = document.getElementById("score");
        const elBest = document.getElementById("best");
        const overlay = document.getElementById("overlay");
        const ovTitle = document.getElementById("ovTitle");

        document.getElementById("yr").textContent = new Date().getFullYear();

        let best = 0;
        try {
          best = parseInt(localStorage.getItem("snakeBest") || "0", 10) || 0;
        } catch (e) {}
        elBest.textContent = best;

        function reset() {
          snake = [
            { x: 10, y: 7 },
            { x: 9, y: 7 },
            { x: 8, y: 7 },
          ];
          dir = { x: 1, y: 0 };
          queue = [];
          score = 0;
          elScore.textContent = "0";
          placeFood();

        function placeFood() {
          const free = [];
          for (let y = 0; y < ROWS; y++)
            for (let x = 0; x < COLS; x++) {
              if (!snake.some((s) => s.x === x && s.y === y))
                free.push({ x, y });
            }
          food = free[Math.floor(Math.random() * free.length)] || {
            x: 0,
            y: 0,
          };
        }

        function draw() {
          ctx.fillStyle = "#161b22";
          ctx.fillRect(0, 0, canvas.width, canvas.height);

          // 网格
          ctx.strokeStyle = "rgba(255,255,255,.03)";
          ctx.lineWidth = 1;
          for (let i = 1; i < COLS; i++) {
            ctx.beginPath();
            ctx.moveTo(i * CELL, 0);
            ctx.lineTo(i * CELL, canvas.height);
            ctx.stroke();
          }
          for (let j = 1; j < ROWS; j++) {
            ctx.beginPath();
            ctx.moveTo(0, j * CELL);
            ctx.lineTo(canvas.width, j * CELL);
            ctx.stroke();
          }

          // 食物
          ctx.fillStyle = "#f85149";
          ctx.beginPath();
          ctx.arc(
            food.x * CELL + CELL / 2,
            food.y * CELL + CELL / 2,
            CELL * 0.32,
            0,
            Math.PI * 2,
          );
          ctx.fill();

          // 蛇
          snake.forEach((s, i) => {
            ctx.fillStyle = i === 0 ? "#3fb950" : "#238636";
            const pad = i === 0 ? 1 : 2;
            ctx.fillRect(
              s.x * CELL + pad,
              s.y * CELL + pad,
              CELL - pad * 2,
              CELL - pad * 2,
            );
          });
        }

        function tick() {
          if (queue.length) {
            const nd = queue.shift();
            if (nd.x !== -dir.x || nd.y !== -dir.y) dir = nd;
          }
          const head = { x: snake[0].x + dir.x, y: snake[0].y + dir.y };

          if (
            head.x < 0 ||
            head.y < 0 ||
            head.x >= COLS ||
            head.y >= ROWS ||
            snake.some((s) => s.x === head.x && s.y === head.y)
          ) {
            return gameOver();
          }

          snake.unshift(head);

          if (head.x === food.x && head.y === food.y) {
            score++;
            elScore.textContent = score;
            placeFood();
          } else {
            snake.pop();
          }
          draw();
        }

        function start() {

          draw();

          if (!running) return;
          paused = !paused;
          if (paused) {

            pauseBtn.textContent = "Resume";
          } else {
            timer = setInterval(tick, stepMs);
            pauseBtn.textContent = "Pause";
          }

          A: { x: -1, y: 0 },

            togglePause();
            return;
          }
          const d = KEYS[e.key];
          if (!d) return;
          e.preventDefault();

**① 最重要的遗漏：没有任何变现方案。** 整套页面方案从头到尾没提广告位怎么放、放几个、用什么平台。这是唯一能验证商业模式的一环——我查了 playsnake.org 的估值快照：**综合估值 $118.4k，参考区间 $31.7k~$189.1k，月收入估算 $2,642~$5,252**（口径：AdSense 广告内容站，DR 48、月流量 19.7 万、搜索占比 48%、域龄 12.9 年）。

**② 广告位我上一轮只说了「别放在游戏区正上方」，没说具体方案。**补上：首页四个位（顶部 728×15 链接单元、左右各一个 160×600 竖幅、移动端底部固定 50px）照 playsnake.org 的布局逻辑做，但**首屏广告绝不能挤到游戏区**——它体验分只有 20/100，我们赢它就在首屏。AdSense 之外可以同步接一家游戏专门的联盟（如 GameMonetize 之类），前期 AdSense 单价最低但门槛也最低。

**④ 收录检查点。**上线后按这个顺序验：GSC 提交 sitemap → 用 `site:snakearcadegame.com` 语法确认被收录（这是哥飞给的判定标志）→ 没收录就手动请求索引。要注意社群看到的两个真实状态：**「已发现-尚未编入索引」可以手动提交救回来，但「已抓取-尚未编入索引」基本是内容问题、要重写内容**（Roody 在 3 群，2026-05-18）。哥飞在同一话题下的回复是：「**其实还是要看页面内容质量的，内容不行的，手动提交也不行。**」——我们那两块正文（How to Play + FAQ）就是为这个准备的。

## 3. `sw.js`

```js
const CACHE = "snake-arcade-v1";
const ASSETS = [
  "/",
  "/manifest.webmanifest",
  "/icon-192.png",
  "/icon-512.png",
  "/apple-touch-icon.png",
];

self.addEventListener("install", (e) => {
  e.waitUntil(
    caches
      .open(CACHE)
      .then((c) => c.addAll(ASSETS))
      .then(() => self.skipWaiting()),
  );
});

self.addEventListener("activate", (e) => {
  e.waitUntil(
    caches
      .keys()
      .then((keys) =>
        Promise.all(
          keys.filter((k) => k !== CACHE).map((k) => caches.delete(k)),
        ),
      )
      .then(() => self.clients.claim()),
  );
});

self.addEventListener("fetch", (e) => {
  if (e.request.method !== "GET") return;
  e.respondWith(
    caches.match(e.request).then((cached) => {
      const net = fetch(e.request)
        .then((res) => {
          if (res && res.status === 200 && res.type === "basic") {
            const copy = res.clone();
            caches.open(CACHE).then((c) => c.put(e.request, copy));
          }
          return res;
        })
        .catch(() => cached || caches.match("/"));
      return cached || net;
    }),
  );
});
```

**执行矩阵页时，记得把每页加进 `ASSETS`**（上线一页加一条，并改 `CACHE` 版本号，否则老缓存不更新）。

  function placeApple() {
    var free = [];
    for (var y = 0; y < ROWS; y++) {
      for (var x = 0; x < COLS; x++) {
        var hit = false;
        for (var i = 0; i < snake.length; i++) {
          if (snake[i].x === x && snake[i].y === y) { hit = true; break; }
        }
        if (!hit) free.push({ x: x, y: y });
      }
    }
    apple = free.length ? free[Math.floor(Math.random() * free.length)] : null;
  }

  function roundRect(x, y, w, h, r) {
    ctx.beginPath();
    ctx.moveTo(x + r, y);
    ctx.arcTo(x + w, y, x + w, y + h, r);
    ctx.arcTo(x + w, y + h, x, y + h, r);
    ctx.arcTo(x, y + h, x, y, r);
    ctx.arcTo(x, y, x + w, y, r);
    ctx.closePath();
    ctx.fill();
  }

  function draw() {
    ctx.fillStyle = "#161b22";
    ctx.fillRect(0, 0, COLS * CELL, ROWS * CELL);

    ctx.strokeStyle = "rgba(255,255,255,.035)";
    ctx.lineWidth = 1;
    for (var gx = 1; gx < COLS; gx++) {
      ctx.beginPath(); ctx.moveTo(gx * CELL, 0); ctx.lineTo(gx * CELL, ROWS * CELL); ctx.stroke();
    }
    for (var gy = 1; gy < ROWS; gy++) {
      ctx.beginPath(); ctx.moveTo(0, gy * CELL); ctx.lineTo(COLS * CELL, gy * CELL); ctx.stroke();
    }

    if (apple) {
      ctx.fillStyle = "#f85149";
      ctx.beginPath();
      ctx.arc(apple.x * CELL + CELL / 2, apple.y * CELL + CELL / 2, CELL * 0.32, 0, Math.PI * 2);
      ctx.fill();
    }

    for (var i = snake.length - 1; i >= 0; i--) {
      var seg = snake[i];
      ctx.fillStyle = i === 0 ? "#3fb950" : "#2ea043";
      roundRect(seg.x * CELL + 1, seg.y * CELL + 1, CELL - 2, CELL - 2, 6);
    }
  }

  function step() {
    if (queued.length) { dir = queued.shift(); }

    var head = { x: snake[0].x + dir.x, y: snake[0].y + dir.y };

    if (head.x < 0 || head.y < 0 || head.x >= COLS || head.y >= ROWS) { return die(); }

    var grow = apple && head.x === apple.x && head.y === apple.y;
    /* 坑 1：撞自己时排除蛇尾——本回合尾部会让出，贴尾转向不该判死 */
    var limit = grow ? snake.length : snake.length - 1;
    for (var i = 0; i < limit; i++) {
      if (snake[i].x === head.x && snake[i].y === head.y) { return die(); }
    }

    snake.unshift(head);

    if (grow) {
      score++;
      scoreEl.textContent = score;
      if (score > best) {
        best = score;
        bestEl.textContent = best;
        try { localStorage.setItem("snakeBest", String(best)); } catch (e) {}
      }
      placeApple();
      if (!apple) { return win(); }
    } else {
      snake.pop();
    }
    draw();
  }

  function start() {
    overlay.hidden = true;
    interval = setInterval(step, tick);
    running = true;
    paused = false;
  }

  function showOverlay(title, text, btn) {
    ovTitle.textContent = title;
    ovText.textContent = text;
    ovBtn.textContent = btn;
    overlay.hidden = false;
  }

  function die() {
    clearInterval(interval);
    running = false;
    showOverlay("Game over — score " + score, "Best " + best + " · press any arrow key to play again", "Play again");
  }

  function win() {
    clearInterval(interval);
    running = false;
    showOverlay("Board filled! Score " + score, "Press any arrow key to play again", "Play again");
  }

  function togglePause() {
    if (!running) { return; }
    if (paused) {
      overlay.hidden = true;
      interval = setInterval(step, tick);
      paused = false;
    } else {
      clearInterval(interval);
      showOverlay("Paused", "Press space or P to resume", "Resume");
      paused = true;
    }
  }

  function turn(nx, ny) {
    /* 坑 2：方向入队而不是直接改 dir——否则快速连按两下会反向自杀 */
    var last = queued.length ? queued[queued.length - 1] : dir;
    if (last.x === -nx && last.y === -ny) { return; }
    if (last.x === nx && last.y === ny) { return; }
    if (queued.length < 3) { queued.push({ x: nx, y: ny }); }
  }

  function go(nx, ny) {
    if (!running || paused) {
      reset();
      turn(nx, ny);
      start();
      return;

    turn(nx, ny);
  }

      touchStart = null;
      return;

  });

const CACHE = "snake-v1";
const SHELL = [
  "/",
  "/play-snake",
  "/classic-snake",
  "/nokia-snake",
  "/snake-unblocked",
  "/manifest.webmanifest",
  "/icon-192.png",
  "/icon-512.png",
  "/apple-touch-icon.png",
];

self.addEventListener("install", (e) => {
  e.waitUntil(
    caches
      .open(CACHE)
      .then((c) => c.addAll(SHELL))
      .then(() => self.skipWaiting()),
  );
});

self.addEventListener("activate", (e) => {
  e.waitUntil(
    caches
      .keys()
      .then((keys) =>
        Promise.all(
          keys.filter((k) => k !== CACHE).map((k) => caches.delete(k)),
        ),
      )
      .then(() => self.clients.claim()),
  );
});

self.addEventListener("fetch", (e) => {
  if (e.request.method !== "GET") {
    return;
  }
  e.respondWith(
    fetch(e.request)
      .then((res) => {
        const copy = res.clone();
        caches
          .open(CACHE)
          .then((c) => c.put(e.request, copy))
          .catch(() => {});
        return res;
      })
      .catch(() => caches.match(e.request).then((r) => r || caches.match("/"))),
  );
});

<section>
  <h2>Why Do Schools and Workplaces Block Game Sites?</h2>
  <p>
    Usually not because of the game itself. Network filters sort the web into
    categories — gaming, social media, streaming, adult content — and then block
    whole categories at once. A page gets sorted into "gaming" and is blocked
    whether it contains one snake game or a thousand.
  </p>
  <p>Three things push a domain into the gaming category:</p>
  <ul>
    <li>
      <strong>Domain reputation.</strong> Filters keep their own lists of known
      game portals. Being on a list is enough — no one reviews the page by hand.
    </li>
    <li>
      <strong>Category and keyword signals.</strong> "Games", "play", "arcade"
      in the URL, the title and the page text are strong hints to an automated
      classifier.
    </li>
    <li>
      <strong>Site history.</strong> A domain that has hosted games before is
      assumed to host games now. This is also why a brand-new game site
      sometimes slips through for a while.
    </li>
  </ul>
  <p>
    So the block is aimed at the category, not at you. That also means there is
    nothing to "hack" — and nothing on this page tries to.
  </p>
</section>

<section>
  <h2>How to Play Without Installing Anything</h2>
  <p>
    This page is a single HTML file with the game built in. Press a key and the
    round starts; there is no installer, no file to download, and no account to

  </p>
